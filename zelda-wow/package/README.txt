ZELDA OF WARCRAFT
=================
World of Warcraft 1.12.1's world (Azeroth), played with Ocarina of Time style controls.
The game client is Benilla, an open-source 1.12.1 client written from scratch, with Zelda changes.
It runs against your own offline Azeroth Solo server.

SETUP
  1. Azeroth Solo must already be set up (its SETUP.bat finished).
  2. Put this ZeldaWoW folder next to the AzerothSolo folder.
  3. Double-click PLAY-ZELDA.bat. Log in with PLAYER / PLAYER.

STATUS
  Early build. See the project page for which Zelda controls are in this version.
